# **SAMPLE SENSOR DATA**

## 1. BM2166 Capacitive Fingerprint Module Profile

### Hardware & Connection

| Item | Details |
| :--- | :--- |
| **Sensor Model** | BM2166 Capacitive Fingerprint Module |
| **Main Chip / Controller** | STM32F407ZET6 (ARM Cortex-M4) |
| **Connection Type** | UART / USB Serial |

### Image & Working Limits

| Feature | Value |
| :--- | :--- |
| **Sensor Touch Area** | 8.0 × 8.0 mm |
| **Clarity / Resolution** | 508 DPI |
| **Pixel Size** | 160 × 160 |
| **Safe Temperature** | -20°C to +40°C |
| **Safe Air Humidity** | 40% to 85% |

### Touch Pressure & Angle (Normal vs. Forced)

| Measurement | Value / Description |
| :--- | :--- |
| **Normal Touch Push Force** | 3.0 N (average) |
| **Forced Touch Push Force** | 20.0 to 45.0 N |
| **Normal Finger Angle** | 90.0° (straight down) |
| **Forced Finger Angle** | 30.0° (diagonal) |
| **High Pressure Spot** | Outer edges of the sensor during forced touch |
